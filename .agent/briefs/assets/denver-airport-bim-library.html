BIM OBJECT — the atom

A single, certified building component.

One product or entity — a door, a jet-bridge cab hinge, a specific luminaire — identified by its IFC 4.3 entity class and its Uniclass 2015 classification at the Products (Pr) or Systems (Ss) level.

It carries manufacturer or generic data plus the applicable property sets and geometric constraints. A BIM Object is never a composed layout — it is the atom that layouts are built from.

COMPOSITION — the assembly

A named template built from many objects.

A Key Plan, tile, space-type or "typical" — assembled from several BIM Objects to satisfy a methodology or code requirement. Classified one tier up, at Uniclass Elements/functions (EF) or Spaces/locations (SL) level.

This is the Revit family-versus-group distinction. A Composition's detail view shows a "Composed from" bill of objects — links to its constituent atoms — not a manufacturer spec sheet.
