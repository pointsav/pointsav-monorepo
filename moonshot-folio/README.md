# moonshot-folio

Owned, native-Rust, zero-third-party-crate rendering engine family (PDF, DOCX, XLSX, CSV; later IFC, DXF, PPTX, .eml). Replaces `tool-typeset` gradually.

Status: skeleton (roadmap task F0.1). Nested standalone workspace, excluded from the monorepo workspace like `service-slm`. Design and state live in the project-source BRIEF set `BRIEF-moonshot-folio-*`.
