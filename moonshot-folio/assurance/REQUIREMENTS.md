# Requirements

Status values: `draft`, `approved`, `verified`. Every REQ needs at least one TRACE row before it can be `verified`.

| ID | Class | Crate | Requirement | Status |
|---|---|---|---|---|
| FOLIO-REQ-001 | determinism | all | Output bytes are a pure function of (Document, Limits, FontBlobs); no clock, environment, locale or random reads | draft |
| FOLIO-REQ-002 | determinism | all | No `HashMap`/`HashSet` iteration in any output path; use ordered collections | draft |
| FOLIO-REQ-003 | determinism | all | Debug and release builds produce byte-identical output; two hosts produce byte-identical output | draft |
| FOLIO-REQ-004 | untrusted-parse | codec, font | Every parser returns `Err` on malformed input and never panics, indexes unchecked, or loops without an iteration budget | approved |
| FOLIO-REQ-005 | untrusted-parse | codec | Inflate enforces an absolute output cap per stream; ZIP enforces entry count and total-size caps | draft |
| FOLIO-REQ-006 | untrusted-parse | core | Each `Limits` field is tested at the limit and at limit+1 | draft |
| FOLIO-REQ-007 | fidelity | core | Unit conversion uses i64 EMU with i128 intermediates and one rounding rule; no `f64` in the IR | draft |
| FOLIO-REQ-008 | fidelity | layout | A missing glyph is reported, never silently dropped: layout fails with `Unsupported` under `Reject`, or lays the character out at the notdef (TrueType) or average (standard font) width and counts it in `PageTree::substituted` under `Notdef`, once per drawn occurrence (a footer counts on every page, a repeated header row on every page it is drawn) | verified |
| FOLIO-REQ-009 | fidelity | xlsx | Formula cells carry caller-supplied cached values; absence is an error | draft |
| FOLIO-REQ-010 | fidelity | codec | SHA-256 matches FIPS 180-4 vectors including 55, 56 and 64-byte padding and the million-a vector | verified |
| FOLIO-REQ-011 | process | all | Zero third-party crates in every manifest and lockfile | draft |
| FOLIO-REQ-012 | process | all | `#![forbid(unsafe_code)]`, no `build.rs`, no proc-macros, no `macro_rules!` except const table generators | draft |
| FOLIO-REQ-013 | process | all | Each crate builds standalone with only its family path dependencies | draft |
| FOLIO-REQ-014 | process | conform | Golden corpus contains only synthetic data | draft |
| FOLIO-REQ-015 | fidelity | codec | CRC-32 and Adler-32 match published known-answer vectors, a bitwise reference, and give identical results streamed or one-shot | verified |
| FOLIO-REQ-016 | determinism | codec | The ZIP writer is deterministic: stored entries, insertion order, fixed DOS timestamp, no extras; names are relative, forward-slash, with no empty, `.` or `..` segment | verified |
| FOLIO-REQ-017 | untrusted-parse | codec | The ZIP reader checks every offset and length, rejects unsafe names, zip64, encryption and unsupported methods, verifies CRC-32 on read, and returns an error (never panics) on any truncation or single-byte corruption | verified |
| FOLIO-REQ-018 | untrusted-parse | codec | Inflate and the zlib wrapper decode RFC 1951 and RFC 1950 streams (stored, fixed, dynamic), enforce an absolute output cap, check Adler-32, and return an error on any malformed or truncated stream | verified |
| FOLIO-REQ-019 | untrusted-parse | codec | The PNG decoder checks the signature and every chunk CRC, rejects interlaced images and unknown critical chunks, enforces the PNG chunk order and tRNS length rules, caps pixel count and decompressed size from the header before allocating, applies all five filters correctly, and converts every colour type and depth to RGBA8 matching an independent oracle | verified |
| FOLIO-REQ-020 | untrusted-parse | codec | The JPEG header parser reads frame facts (size, components, precision, progressive, Adobe transform) from SOF0 to SOF2, rejects other frame types, zero or oversized dimensions and malformed segments, and never panics on truncation or corruption | verified |
| FOLIO-REQ-021 | determinism | core | Lengths are integer EMU with checked arithmetic and one rounding rule (half away from zero, `i128` intermediates); overflow and zero denominators are errors | verified |
| FOLIO-REQ-022 | fidelity | ir | `validate()` rejects an IR that breaks its invariants (language tag, date, page geometry, heading level, image alt text and size, calendar-correct dates, page sides up to 200 inches, grid spans, decimal numbers, sheet-name rules, duplicate sheets, cell limit) so backends may assume them | verified |
| FOLIO-REQ-023 | fidelity | ir | The capability matrix answers Native, Degraded(reason) or Rejected(reason) for every feature and target; `check_target` fails on any rejected feature and reports degradations; adding a feature is a compile error until each target has an answer | verified |
| FOLIO-REQ-024 | fidelity | compat-typeset | The tool-typeset adapter converts every Block kind, quantises points to hundredths then EMU with the family rounding rule, pads short table rows, rejects over-wide rows and non-finite lengths, reports each lossy mapping in notes, and yields an IR that passes validate() | verified |
| FOLIO-REQ-025 | fidelity | conform | Golden corpus group tt/ holds 19 synthetic scenarios modelled on the tool-typeset test suite; each converts deterministically through the adapter, validates, and matches its stored canonical IR dump (including loss notes); goldens regenerate only with FOLIO_BLESS=1 | verified |
| FOLIO-REQ-026 | fidelity | docx | The DOCX writer emits a deterministic package (fixed part order, store-only ZIP, caller-supplied properties, no clock), well-formed XML parts, XML-escaped text, twip page geometry, and rejects workbooks and text XML cannot carry | verified |
| FOLIO-REQ-027 | fidelity | docx | Paragraphs, headings, runs (bold, highlight, role styles), tabs and line breaks, page and line breaks, simple fields, bookmarks and hyperlinks (http, https, mailto, #anchor only), pagination hints and multiple sections are written as well-formed WordprocessingML; role names map to injective style ids; unsafe link targets and invalid anchor names are rejected | verified |
| FOLIO-REQ-028 | fidelity | docx | Tables are written with a `tblGrid` over the section content width (remainder in the last column), `gridSpan` for spans, `tblHeader` for repeated header rows, `cantSplit` for non-splitting rows, a closing paragraph in every cell, right-aligned numbers and role styles | verified |
| FOLIO-REQ-029 | fidelity | docx | Section headers and footers are written as separate parts with relationships and content types, referenced from `w:sectPr` ahead of page geometry; a distinct first page suppresses the header but keeps the footer; chrome content is validated; external links in chrome are rejected | verified |
| FOLIO-REQ-030 | fidelity | docx | Lists are written as numbered or bulleted paragraphs referencing a generated `numbering.xml` (one `w:num` per IR numbering id, numId by first use), with its content type, relationship and `ListParagraph` style; the part exists only when a list is used; one numbering id cannot be both ordered and bulleted | verified |
| FOLIO-REQ-031 | fidelity | docx | `w:updateFields` is set (via a settings part) whenever the document uses PAGE, NUMPAGES or TOC fields, including in headers and footers, and only then; a section can restart page numbering at 1 (`w:pgNumType`) | verified |
| FOLIO-REQ-032 | determinism | docx | A document using every DOCX writer feature renders to identical bytes on repeated runs and every part is well-formed | verified |
| FOLIO-REQ-033 | fidelity | csv | CSV output follows RFC 4180 (CRLF records; quoting on comma, quote, CR, LF; doubled quotes), neutralises formula-looking text by default but never alters numbers, offers an optional BOM, is deterministic, and rejects flow bodies, merged cells, bad sheet indices and oversize output | verified |
| FOLIO-REQ-034 | untrusted-parse | ir | Sheet widths, frozen panes, defined names (syntax, not cell-like, in range, unique workbook-wide) and formulas (on an existing cell with a non-empty cached value, unique per cell, text limited to a character and function whitelist) are validated before any backend runs | verified |
| FOLIO-REQ-035 | fidelity | xlsx | The XLSX writer emits a deterministic package of well-formed parts with inline strings, typed cells, merged ranges for spans, de-duplicated cell styles (bold, italic, rules, fills, number formats, alignment), column widths, frozen panes, fit-to-width landscape printing and workbook defined names; CMYK colours, bad number formats, flow bodies and oversize sheets are rejected | verified |
| FOLIO-REQ-036 | fidelity | xlsx | Every formula cell is written with its formula text and the cell value as its cached result; a formula on an empty cell or with non-whitelisted text is rejected | verified |
| FOLIO-REQ-037 | fidelity | xlsx | Data validation (list, whole number between) and conditional formatting (cell-value comparison styled through a differential format) are written in schema order; bad lists, ranges, values and roles without a style are rejected | verified |
| FOLIO-REQ-038 | untrusted-parse | font | The TrueType parser checks the sfnt directory, head, maxp, hhea, hmtx, loca, glyf and cmap (formats 4 and 12) against the file bounds and glyph limit, rejects CFF, collections and fonts without a Unicode cmap, exposes metrics, glyph lookup, advances, raw glyph bytes, fsType, post and PostScript name, never panics on any truncation or single-byte corruption, and agrees with fontTools on system fonts | verified |
| FOLIO-REQ-039 | fidelity | font | The subsetter preserves glyph ids, keeps requested glyphs and composite components (bounded by depth and component count, cycles safe), empties the rest, keeps cvt/fpgm/prep, rebuilds loca and head with a correct checksum adjustment, is deterministic, and its output re-parses and loads in fontTools | verified |
| FOLIO-REQ-040 | fidelity | font | Embedding is refused when OS/2 fsType forbids it (restricted, bitmap-only, or no-subsetting when subsetting), and characters missing from a font are either rejected or mapped to notdef with a count, per policy | verified |
| FOLIO-REQ-041 | fidelity | font | Helvetica and Helvetica-Bold standard-14 widths (ASCII, Latin-1, common typographic punctuation) match the Adobe AFM files by WinAnsi glyph name, fall back to the font average only for uncovered characters, and expose the base font name | verified |
| FOLIO-REQ-044 | fidelity | pdf | The PDF writer emits a classic cross-reference table with exact offsets, converts EMU to points with integer-only arithmetic (A4 is 595.276 x 841.89), and builds the Info dictionary and `D:YYYYMMDD000000Z` date only from caller-supplied values | verified |
| FOLIO-REQ-045 | fidelity | pdf | An embedded TrueType font is written as a glyph-id-preserving subset in a Type0 / Identity-H / CIDFontType2 font with /W, a FontDescriptor and a ToUnicode map, honours check_embedding, extracts exactly through pdftotext (accents and the euro sign included) and opens cleanly in Ghostscript | verified |
| FOLIO-REQ-046 | fidelity | pdf | URI link annotations, named destinations, explicit page-position destinations and a nested bookmark outline with correct /Count are accepted by pdfinfo and Ghostscript without warnings | verified |
| FOLIO-REQ-047 | determinism | pdf | Building the same document twice yields byte-identical files; /ID derives from the SHA-256 of the file body; no clock or environment input | verified |
| FOLIO-REQ-048 | untrusted-parse | pdf | The writer rejects URIs that are not http, https or mailto (or hold spaces, control or non-ASCII characters), characters a standard font cannot encode unless substitution is chosen, unbalanced graphics state, dangling page or destination references, and content, counts, depth or file size beyond Limits; all strings and names are escaped | verified |
| FOLIO-REQ-049 | fidelity | docx | Review findings D1-D11 stay fixed: each ordered list restarts at 1; a section without a header or footer gets an empty part instead of inheriting; paragraph and run styles never share an id and style names are unique ignoring case; no header, footer or body ends in a bare table; widow control is not disabled by default; header and footer distance follows the margin; CR and CRLF become line breaks; anchors start with a letter, are unique and every internal link has a target; empty run roles are plain text; the capability matrix does not claim DOCX images | verified |
| FOLIO-REQ-042 | fidelity | text | line_breaks agrees with the ICU 74.2 line-break oracle on a deterministic corpus of 88,729 strings (class pairs and triples, hand-picked tricky text, seeded random mixes) apart from three documented, individually classified tailoring differences (LB25 number regex both directions, LB20a after GL) | verified |
| FOLIO-REQ-043 | fidelity | text | The Line_Break table is a checked-in constant table generated from Unicode 15.0.0 by gen/make_tables.pl, with the LB1, quotation, East Asian bracket, emoji and regional-indicator refinements folded in and spot-checked | verified |
| FOLIO-REQ-050 | fidelity | text | Break offsets are strictly increasing, inside the text, on char boundaries and end at the text end; hard terminators force a mandatory break; CRLF is never split; no break precedes closing punctuation or falls between ASCII letters | verified |
| FOLIO-REQ-051 | untrusted-parse | text | line_breaks and wrap never panic for any Unicode scalar value, arbitrary or mutated input, or runs of 100,000 combining marks or regional indicators, and run in linear time on those runs | verified |
| FOLIO-REQ-052 | fidelity | text | wrap ends a line at the last allowed break that fits, always at a mandatory break, ignores trailing spaces in the width, and cuts an overlong word at a char boundary so every line holds at least one char | verified |
| FOLIO-REQ-053 | untrusted-parse | ir | Review findings X1-X7 and C2 stay fixed: defined names may not use the _xlnm. prefix or read as R1C1 references; sheet names obey Excel (UTF-16 length, no edge apostrophes, not History, Unicode case-insensitive uniqueness); formulas cannot hide a function name behind a space, use semicolons, nest past 64 levels or start or end with an operator; number-format codes need balanced quotes and brackets and at most four sections; formula, validation and format counts are limited and handled in linear time; numbers are at most 40 characters; CSV rejects control characters | verified |
| FOLIO-REQ-054 | untrusted-parse | font | Review findings F1-F8 stay fixed: loca must be non-decreasing and end inside glyf (no aliasing amplification, subset output bounded by glyf and by max_file_bytes); cmap format 4 uses a binary search over validated sorted endCodes; a damaged OS/2 or a head under 54 bytes is rejected (fail closed); PostScript names with delimiters or over 63 characters are never returned; composite depth is checked only when following a component and truncated composites are rejected; the closure work stack only holds unvisited glyphs | verified |
| FOLIO-REQ-055 | fidelity | layout | Paragraphs, headings, lists and inline runs are broken into lines with the UAX#14 greedy wrapper using integer-EMU advances from the standard-14 tables or a TrueType font (sum of per-character rounded advances); trailing spaces and line terminators hang outside the line; lists hang a marker in a uniform indent; every text item, rectangle and link lies inside the page's content box and no two text boxes overlap | verified |
| FOLIO-REQ-056 | fidelity | layout | Pagination honours widow and orphan control (two lines each side when asked), keep-with-next for headings and flagged blocks (a chain moves together), page-break-before and explicit page breaks (never a blank page), and every section starts a new page with its own size, margins and numbering (restart at 1 on request); a page break takes effect only when content follows it in its section, so none leaves a blank page, and a section with no placed content gives no page (one blank page if no section has any); a keep-with-next chain moves as a whole when the rest of it fits a page, and is otherwise kept with the start of its successor on a best-effort basis (open limit: a chain taller than a page cannot satisfy every link); a block that cannot split (too few lines for widow and orphan control) is reserved whole beside a heading; page count never shrinks when content is appended | verified |
| FOLIO-REQ-057 | fidelity | layout | Tables place rows whole, split only between rows, repeat the leading header rows on every continuation page (marked `repeated` on the items; not when they would fill over half a page or when the next row fits a page alone but not beside them), cut only a row taller than the page by line without losing text and in time proportional to its size (80000 words in a cell in under 0.2 s in release), draw cell rules inset by half their width so strokes stay inside the content box (open limit: a border shared by two cells is drawn twice, so it looks twice as thick), give column spans the width of the columns they cover with the remainder in the last column, right-align numbers, and reject columns too narrow for their padding | verified |
| FOLIO-REQ-058 | fidelity | layout | Headers and footers are laid out inside the content box on every page (the first page may drop the header); page-number fields show the page where the line lands, with the width of the label itself (a placeholder reserves the widest digits and the rest of the line follows the real number), and page-count fields are resolved by repeating layout until the count it produces equals the count it assumed (at most eight passes, shared with the contents fixed point; otherwise `Limit`; the loop is unit-tested with a driver that never settles, because no document is known to oscillate) | verified |
| FOLIO-REQ-059 | fidelity | layout | Hyperlinks become URI or named-destination annotations with the rectangle of their text, anchors become named destinations at the top of their line, an unknown link target, an empty link target, an empty anchor name and a duplicate anchor are rejected (anchors inside headers and footers are not recorded), and every item carries the stable IR index path of its node and a structure role (paragraph, heading level, list item, table cell, header, footer, link, artifact) from which table, row and cell ancestors follow by path prefix | verified |
| FOLIO-REQ-060 | determinism | layout | Layout is a pure function of (document, fonts, theme, options): two runs give equal trees and identical canonical dumps, all arithmetic is checked integer EMU, and the golden corpus assurance/golden/layout regenerates only with FOLIO_BLESS=1 | verified |
| FOLIO-REQ-061 | untrusted-parse | layout | Layout validates the IR first and never panics: images, a table of contents inside a paragraph, header or footer, workbooks, page breaks in headers and footers, glyphs wider than their line, content taller than the page body and a header and footer that leave no room are errors; pages are capped at max_zip_entries, placed items and wrapped lines at max_cells and measured text at 256 characters per max_cells unit (charged before it is built, so a huge paragraph fails fast); theme rule width and list indent are bounded; mutated and random documents either lay out inside the content box or fail with an error | verified |
| FOLIO-REQ-062 | fidelity | layout | `Block::Field(Toc)` in a section body lists every body heading (the IR field has no level range) as an indented entry with its title (wrapped when long), a dot leader and the page label right-aligned, linked as a whole to a named destination the heading receives; the entries come from the previous pass and layout repeats (at most eight passes, otherwise an error) until entries, page count and number widths no longer change, so every number equals the page its heading is finally on even when the contents spans pages or moves the headings; a document without headings gets no output from the field; headings in headers and footers are not listed; a contents inside a paragraph, header or footer is rejected; headings are found by their IR block (a heading made only of links is listed; one with no visible text is neither listed, bookmarked nor given a destination); a title is joined across line breaks with a space only where the line ended at a dropped space (so hyphen, mid-word and address breaks leave the text exact: `TextItem::space_after`); anchors named `folio-toc-...` are rejected as reserved, with or without a contents; the link of an entry covers the gap before the leader; the indent is clamped so deep levels still leave the title four ems; entries carry node `[section, 0, block, entry]` with role Link for title and number and Artifact for the leader | verified |
| FOLIO-REQ-063 | fidelity | pdf | `render_pdf` lays a document out and writes one page per laid-out page with its text (standard fonts or embedded TrueType by `Fonts` slot), filled and stroked rectangles, URI and named-destination link annotations, named destinations from the tree, an outline nested from the heading levels (a skipped level still nests under the nearest lower level) an information dictionary from the document metadata and caller-supplied strings and date, never a clock, the document language as /Lang, and /PageLabels (decimal, one run per restart of numbering) so the viewer's page numbers are the labels the contents shows; repeated table header rows are drawn like any other item; bookmark titles beyond the title limit are cut at a character boundary and bookmarks and destinations are counted against `max_cells`, not the page limit; checked by parsing the output bytes (page tree and /Count, content text and rectangles, fonts, annotation rectangles, /Names positions, outline structure, titles and positions, /PageLabels, /Lang) | verified |
| FOLIO-REQ-064 | determinism | pdf | Rendering the same document twice gives identical bytes with a content-derived /ID; an embedded TrueType font used for regular and bold is embedded once and its text extracts exactly through the `ToUnicode` map (accents, euro sign, quotes, dashes); an embedded font is parsed only when a character not seen before arrives, not for every text item; page labels in the file equal the labels of the layout; contents page numbers in the rendered file equal the pages that hold the headings, including two-digit numbers | verified |
| FOLIO-REQ-065 | untrusted-parse | pdf | Errors from layout and the writer reach the caller unchanged: a link scheme other than http, https or mailto, a character a standard font cannot encode (an error under Reject, `?` under Notdef), a workbook body, an invalid or non-calendar creation date (IR validate and the writer agree: month 1-12, day within the month, leap years) and a page count over `max_zip_entries`; a page side over 200 inches fails in layout before any page is built; a refused link is reported by reason only (errors carry static text), and `bad_links` names the links; tests needing a system font fail when it is missing unless `FOLIO_ALLOW_MISSING_FONT=1` | verified |
